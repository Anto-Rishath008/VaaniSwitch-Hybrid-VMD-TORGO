# V4 WavLM post-hoc exploratory protocol

Prepared 2026-10-13, Asia/Calcutta. Separate research only; Modules 0-6 and the signed shared-VMD architecture stay frozen. All V4 writes remain inside experiments/accuracy_wavlm_v4. No commits or pushes.

TORGO CORE contains 8,673 original logical speaker/session/prompt recordings, 15 speakers (8 dysarthric, 7 control). Read-only V2 Corpus preserves the signed manifest, original three outer folds, primary microphone choice, labels, paths and audio hashes. V3 grouped development CV is reused unchanged. Each outer context has ten development speakers; every inner validation speaker is absent from its training role. Logical ID, speaker, path and source hash intersections must be empty. Historical outer results never enter selection functions. Original outer results were already exposed; future V4 comparisons are POST-HOC EXPLORATORY, never independent confirmation.

Official model: microsoft/wavlm-base-plus, revision 4c66d4806a428f2e922ccfa1a962776e232d487b. Model/configuration/processor checksums and dependencies live in configs/model_lock.json. No silent revision change or substituted checkpoint. The 94,381,936 pretrained parameters come from Microsoft, not team training. Source: https://huggingface.co/microsoft/wavlm-base-plus/tree/4c66d4806a428f2e922ccfa1a962776e232d487b . Installed transformers 4.57.6 source and https://huggingface.co/docs/transformers/model_doc/wavlm were inspected.

Decode verified primary WAV as float32, average channels, polyphase-resample to 16 kHz if needed. Official WavLM processor has do_normalize=false and return_attention_mask=true. Preserve both; do not copy HuBERT's waveform normalization. Silence is accepted if finite. Empty/non-finite input or fewer than 400 resampled samples stops with the record identity; no recording is silently excluded or replaced. CORE header/length coverage is audited. Center crop to at most eight seconds for A and four seconds for B, for both train and evaluation. No random cropping, augmentation, multi-crop, or extra segment endpoint. Each original recording yields one prediction. Batch one avoids GroupNorm padding dependence; frame masks are convolution-derived and pooling excludes padding. Population SD is used for A mean+SD. No pooled padded frames count as speech.

A: frozen eval-mode FP32 WavLM hidden states 9/12, masked mean (768) or mean+SD (1536), train-weighted StandardScaler, L2 logistic regression. C in {0.01,0.1}, lbfgs, max_iter 3000, seed 42, convergence warnings fail. Cache identities bind source audio, record, exact model files, preprocessing source, dependency versions, crop and checksums.

B: frozen convolution frontend, feature projection, positional convolution, encoder normalization and lower blocks. Train last 2 or last 4 transformer blocks; masked mean then LayerNorm(768), dropout 0.1, Linear(768,1). A3 adds Linear(768,32), tanh, bias-free Linear(32,1) attention pooling for last 2 only. Frozen modules stay eval-mode; trainable blocks/head train-mode. LayerDrop and SpecAugment disabled. No entire-encoder fine-tuning. FP32 without autocast or GradScaler. Non-reentrant gradient checkpointing for trainable blocks, physical batch 1, accumulation 8, gradient norm clip 1, AdamW, backbone LR 1e-5, head LR 1e-4, weight decay .01. Linear decay over planned updates, at most 8 epochs, patience 2. Inner validation macro-F1 chooses epoch; earliest wins exact ties. Final development refit uses the median of three selected best epochs, without outer validation.

Weight w_i=N/(S*n_s) uses current training records only. Each speaker has equal objective mass; no additional class weight or weighted sampler. Class masses may differ with speaker class counts and are reported. Neural accumulated loss is sum(w_i*BCE_i)/actual group size, including final partial group. Every record appears once per epoch in RNG-seeded shuffle order; no failed batch is skipped. No fitted feature scaler in B; per-record/head LayerNorm parameters learn only from training data.

Check input, features, masks, pool, logits, losses, all intended gradients, gradient norm, model parameters, optimizer and scheduler tensors for finiteness. Strict deterministic algorithms are required, with only PyTorch math SDPA enabled; flash, memory-efficient and cuDNN SDPA are disabled consistently for forward and checkpoint recomputation. A bounded implementation rerun exposed resume drift with inherited warn-only/memory-efficient attention, and that unsuccessful run remains evidence. The deterministic policy is an implementation correction before development selection, not performance-driven tuning. Numerical failure stops and retains diagnostics. GPU allocator limit .8. OOM budget is zero retries at physical batch one: retain last completed update, exact failed record IDs and memory; stop. Never shorten sequences or alter settings after OOM. A reviewed manual resume restores the same configuration and replays unsaved work, never silently skips it.

Checkpoints store trainable model deltas plus checksum-bound immutable official base identity, AdamW, scheduler, completed epoch/update, current shuffled order/offset, best metric/reference, patience, Python/NumPy/Torch CPU/all CUDA RNG, configuration and partition identity. Complete accumulation updates only; periodic interval 1000 updates and each epoch. Unique payload files, fsync/atomic rename then pointer; checksum before deserialization. Incomplete files remain evidence and never become completed state. LR interrupted optimization restarts deterministically from the start; no sklearn internal optimizer resume claim.

Full development and real outer inference are distinct authorized modes. All three selections/final checkpoints freeze before any outer inference. Outer claim is atomically consumed before forwarding; unsealed consumed claims require review, never automatic retry. Completed reports/checkpoints/caches cannot be overwritten. Threshold .5. Report equal-fold arithmetic mean and sample SD (ddof=1), all original recording predictions, descriptive speaker mean probabilities, class rates, ROC-AUC, per-speaker accuracy, variability, timing and memory. Undefined single-class rates are null. No guaranteed accuracy, clinical, SOTA, causal or significance claims.

This session: implementation, automated tests and bounded development CUDA validation only. Full development and real outer inference require separate later approvals. Untouched speakers or an appropriate external corpus with frozen label/preprocessing/evaluation contracts are required for independent confirmation; no external data or adapter is fabricated.
