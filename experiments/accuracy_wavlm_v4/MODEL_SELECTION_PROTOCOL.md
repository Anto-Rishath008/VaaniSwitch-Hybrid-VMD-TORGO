# Frozen development selection rules

1. Reuse V3's three grouped CV buckets within each original outer context's ten development speakers. Class-stratified speaker order hashes ['v3-cv',42,outer_fold,label,speaker]; round-robin buckets. Keep original outer folds unchanged. Each speaker validates exactly once per context; both classes are present in each role.
2. Start with A: eight candidates = layers {9,12} x pooling {mean,mean_std} x C {.01,.1}. Fit scaler and inverse-frequency speaker weights on each training role only. No V2/V3 sealed predictions, scores, difficult-speaker identities or speaker-specific corrections are selection inputs. After all V4 decisions freeze, report the WavLM frozen reference against the protected V3 frozen-HuBERT reference on the same grouped CV definition. This is a descriptive comparison of development-selected references with differing grids, not independent confirmation or a V4 selection input. No new HuBERT search is added.
3. Only after A implementation, tests and bounded CUDA validation succeed, run three B candidates: last2+mean, last4+mean, last2+compact-attention. LR, decay, seed, segment, threshold, batch and scheduler settings are fixed in configs/study.json. No automatic deeper tuning, other head or grid expansion.
4. Select by mean development macro-F1 across three folds, then balanced accuracy, recording accuracy, ROC-AUC, lower log loss, lower complexity (A=0; B=depth plus attention flag), lexical candidate ID. No rounded comparisons. Report sample SD and all candidates including unfavorable ones. Speaker accuracy and per-speaker metrics are descriptive, never selection overrides.
5. Neural early stopping selects strictly improved validation macro-F1; exact epoch ties keep earliest. Patience 2, max 8. Final refit uses median best epoch from the three inner fits. Normalize and weight with all ten development speakers only. Refit best frozen A and overall winner (reuse if identical).
6. Freeze all contexts, source/dependency/model/data identities, selected configs and checkpoint checksums together. Later outer inference uses separate --authorize-outer and once-only claims. It cannot reselect candidates, epochs, thresholds or crop policies.

Budget: 11 candidates x 3 development CV folds x 3 outer contexts = 99 candidate fits (72 LR and 27 neural), plus at most 6 final fits. Up to 8 epochs per neural fit, one seed. No additional candidates without documented development-only justification and a new explicitly reviewed protocol. Small speaker count, overlapping development populations, nested selection optimism and prior exposure limit generalization claims. Selecting B is not required: retain A if it wins.

Bounded smoke overrides only validation resources: eight development training recordings, two validation recordings, one epoch, accumulation four, checkpoint each update. These are infrastructure checks, not development performance evidence; no smoke metric enters production selection. All three neural architectures run; a separate interrupted last2 fit must match its uninterrupted counterpart exactly.
